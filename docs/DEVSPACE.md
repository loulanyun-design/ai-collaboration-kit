# DevSpace integration

DevSpace is optional and is not redistributed in this repository. Use it as a local file/command transport, while Runner remains the controlled delegation path.

Recommended settings: `DEVSPACE_TOOL_MODE=minimal` and `DEVSPACE_SUBAGENTS=0`.

The included hidden-launch example expects `%USERPROFILE%\.devspace\start-devspace-longterm.ps1` to already exist.
